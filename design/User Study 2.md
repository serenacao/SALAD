The User was able to complete all of the tasks within 15 minutes while describing thoughts aloud, which implies the tasks weren't overly complex.

Navigating to the tabs needed to do the different tasks wasn't particularly intuitive to the User, so they often had to check multiple tabs to find where they needed to go. For example, the Invitations tab, where users can find challenges they've been invited to, was where the User originally navigated to both send/view friend requests and send/review verification for completing challenge components, as the word invitation isn't specific to a particular concept or action.

After the User was able to navigate to the correct tab to create/accept friend requests, however, they found it easy to complete those actions.

The User expressed appreciation for how detailed the create challenge form was, although they revealed a bug where if a non optional field in the form was deleted (all fields are populated with defaults) and left blank upon submission, they would be redirected to the main challenges screen as if the challenge was successfully created, but the challenge would not be visible anywhere. This opened a dialogue in the debrief about a desire for better error checking, as incorrect actions on the User's part, such as logging in with incorrect credentials, leaving a field blank, or trying to complete a closed challenge, would fail silently, leading to confusion at times.

Overall, the User found the main social aspects of friending and chatting, along with creating and completing challenges relatively simple to do, but desired more guidance in navigation and user missteps.

More key areas of improvement:

**Flaw:** User got confused/stuck when they filled forms incorrectly

**Cause:** silent failures send the app to an incorrect state without letting the user know that it did so or why

**Potential Solution:** instead of redirecting, have a pop up with the error message so the user has more of an idea of how to proceed
